# 이 대화의 작업 정리와 다음 작업 안내

정리 기준일: 2026-09-30. 이 대화의 사용자 요청, 현재 프로젝트 문서와 검사 기록을 바탕으로 작성했다. 모든 과거 발언을 그대로 옮긴 원문 기록은 아니다.

## 1. 가장 중요한 현재 상태

게임은 세가 새턴의 **랑그릿사 I & II 드라마틱 에디션**이다. 원래 Claude로 진행하던 한글화와 롬 개조 작업을 이어 받았다.

한글화와 개조는 따로 관리한다.

| 작업 | 수정할 위치 | 정본 |
|---|---|---|
| 대사, 이름, 메뉴, 글꼴 | `한글화/` | `한글화/build/worksheet_dedup_final.json`과 이름·용어 JSON |
| 아이템, 가격, 경험치, 상점 | `개조/` | `개조/data/balance/*.json`, `개조/data/code_patches.json` |

개조판은 완성된 한글화 결과를 읽어 추가 수정한다. 한글화 파일을 덮어쓰거나 번역문을 복제하지 않는다. 한글화만 바꾼 뒤 개조판에도 반영하려면 한글화 빌드 → 개조 빌드 순서로 실행한다.

현재 작업은 `한글화`와 `개조`에서 한다. `Next`와 `kr-patch`는 이전 보관본이며 이번 GitHub 정리 대상에서 제외했다.

## 2. 한글화 기본판에 포함한 원작 버그 4종

사용자가 타인의 한글 패치에서 아래 네 수정을 가져오라고 요청했다. 기본 한글판에 포함하고 개조판도 상속한다.

1. 에그베르트 퇴각 횟수 오류.
2. 용병 고용 수 +2가 적용되지 않는 오류.
3. 에스트·오스트의 엘레멘탈 고용 불가 오류.
4. 시나리오 10에서 발가스 격퇴 후 레온 음성이 빠지는 오류.

타인 패치의 랑그릿사 1 캐릭터 이름 볼드 수정은 이 네 항목에 포함하지 않았다. 타인의 숨겨진 상점 변경도 가져오지 않았다. 제작자의 별도 배포 설명 글은 사용자가 찾지 못했다고 답했다.

관리 파일은 `한글화/scripts/bugfixes_l2.py`다. 최종 상태는 `verify_base_fixes.py`가 검사한다. 자세한 기록은 `한글화/docs/원작버그수정_20260915.md`에 있다.

## 3. 캐릭터 메이킹 A수정·D수정 오류와 해결

사용자는 다음 워록 메이킹 선택에서 결과가 이상하다고 알렸다.

> 후퇴한다 → 존재하지 않는다 → 자신의 힘 → 정찰대를 구하러 간다 → 통솔력 → 강대한 힘 → 소수정예 → 사랑하는 사람을 지키려고

사용자 비교 결과, 8월 29일 이전 KR v1.2에는 해당 오류가 없었으나 9월 15일 한글화판은 7/7이었다. 첫 수정판도 2/0으로 잘못 나왔다.

원인은 용병 수 +2 수정이 공용 증가 계산을 바꾸어 메이킹 계산까지 건드린 것이었다. 현재 수정은 **용병 수 +2 명령만 별도로 처리**하고, A수정·D수정을 포함한 다른 증가 계산은 원래 함수를 사용한다.

사용자가 이후 실제 메이킹 화면의 **4/4**를 확인했다고 알렸다. 어느 판을 실행했는지는 특정하지 않았으므로 두 판 모두 화면 확인을 마쳤다고 기록하지 않는다. 두 판의 공통 한글화 코드 검사는 통과했다.

### 유지보수에 필요한 위치

- 원래 설정·증가 함수: `LANG2.BIN 0x178C4–0x17917`. 원본 바이트를 보존한다.
- 특별히 처리할 명령: `4A 06 02`(용병 수 +2).
- 새 처리 코드: 원래 비어 있던 `0x65B00–0x65BFF`.
- 호출 주소 수정 위치: `0x63834`.
- 메이킹 장면 블록 98에는 해당 용병 수 명령이 없다. 메이킹 계산을 새 코드로 보내면 안 된다.

검사 7개와 두 빌드의 파일 검사가 통과했다. `Langrisser_KR_20260916_ADfix.chd`는 실패했던 첫 수정판이며 사용하지 않는다. 9월 15일 CHD도 오류 비교용이다. 이 두 파일은 이번 저장소에 넣지 않았다.

## 4. 아이템 설명 조사

메사이얀소드와 홀리로드의 설명에 수치가 안 보인다는 제보를 받았다.

- 메사이얀소드: 수치 자체는 있었으나 마지막 숫자가 다음 줄로 밀렸다. 일반 아이템 설명 118곳의 수치 줄을 `AT-4 DF-3 A수정-2`로 줄였다. 제보한 화면 현상 전체를 게임에서 재현한 것은 아니다.
- 홀리로드: 일본어 원문부터 숫자 없이 ‘마법능력이 상승’이라고 설명한다. 번역에서 숫자를 누락한 것이 아니다. 실제 효과는 마법 사정거리 +2, 마법 위력 +1, 마법 내성 +30이다. 설명과 능력치는 그대로 두었다.

‘효과 불명’이라는 메사이얀소드 설명도 원문 표현으로 유지했다. 개조판에서 경험치 효과를 옮겼다고 설명을 임의로 바꾸지는 않았다.

## 5. 말투 조사

사용자가 주인공의 ‘~한 게지’ 같은 어색한 말투를 지적해 랑그릿사 2 대사를 조사했다.

- 조사한 대사 위치: 13,033개.
- 바꾼 고유 대사: 70개.
- 문맥상 정상으로 둔 예외: 519개.
- 같은 기준으로 다시 조사했을 때 남은 후보: 0개.

대사·원문·앞뒤 문맥을 함께 비교했다. 기록은 `한글화/docs/말투_재검수_20260915.md`와 관련 조사 자료에 있다. 잔여 후보 0개는 정한 말투 검사 기준의 결과이며 모든 번역이 완벽하다는 뜻은 아니다. 대사창과 시스템 문구를 구분하는 요구를 유지하며, 새 수정 때도 문구 종류와 문맥을 확인한다.

## 6. 개조 내용이 바뀐 과정과 최종 결정

중간에는 크라운 경험치 효과, 룬스톤 판매, 엔젤·페어리 고용 추가, 용병 혼합 고용 등 여러 구성을 만들고 조사했다. 사용자가 메이킹 결과와 페어리 고용 문제를 보고했으며, 이전 개조 문서에는 지금 쓰지 않는 기능도 남아 있다.

**2026-09-30 최종 개조는 랑그릿사 1·2 모두 아래 네 항목이다.**

1. 경험치 2배 효과를 메사이안 소드에서 크라운으로 이동.
2. 크라운 마법 내성 +20 유지.
3. 크라운·룬스톤 모두 10P.
4. 첫 스테이지 상점은 나이프·크라운·룬스톤 3개. 스몰실드를 빼고 마지막 칸은 목록 종료값 0.

제거한 기능: 5차 직업 엔젤 추가, 1차 직업·초기 목록 페어리 추가, 용병 혼합 고용, 혼합 고용 환급 보조 코드.

가격 표의 내부 값 1이 게임 표시 10P에 해당한다. 원래 룬스톤 값 1500은 표시 15000P였다. 이 현재 개조판에서는 사용자 최종 요청에 따라 값 1을 쓴다.

직업표와 제거한 고용 코드 영역은 한글화 기본판 상태로 돌렸다. 한글판 자체에는 크라운·상점 개조가 없다. 원작 버그 4종 수정은 두 판 공통으로 유지한다.

최종 개조 비교에서 `LANG1.BIN`, `LANG2.BIN`이 각각 16바이트 바뀌었다. 글꼴, 번역 장면 데이터, 직업표, 제거한 고용 코드는 한글화 기본판과 같음을 검사했다. 근거는 `분석/개조설정변경_20260930/final_verification.json`과 `verify_profile.py`다. 두 빌드가 끝난 뒤 이 검사 도구를 다시 실행할 수 있다.

## 7. 최신 실행 파일과 배포 파일

- `1.3V/랑그릿사 I&II 1.3V 한글판.chd`
- `1.3V/랑그릿사 I&II 1.3V 개조판.chd`
- `1.3V 패치/한글판/`, `1.3V 패치/개조판/`
- 같은 폴더의 각 배포 ZIP.

배포 패치는 원본 6트랙을 검사하고 첫 트랙에만 차이 파일을 적용한다. 다른 트랙은 그대로 복사한다. 잘못된 원본이나 기존 출력 폴더가 있으면 멈추며 덮어쓰지 않는다. 필요한 xdelta 실행 도구와 라이선스, 적용 설명서가 들어 있다.

현재 개조 배포 패치를 원본에 실제 적용해 빌드 결과와 같음을 확인했다. 배포 ZIP 내용 비교와 CHD 파일 검사도 통과했다. 현재 크라운·룬스톤 구성의 게임 화면을 새로 확인한 것은 아니다. 전체 게임·모든 분기의 플레이 검증도 완료하지 않았다.

## 8. 이번 GitHub 정리 요청

처음 ‘프로젝트 전체’ 요청을 과거 백업까지 포함하는 것으로 해석했지만 사용자가 바로잡았다. 최종 요구는 다음과 같다.

- 비공개 저장소 1: 현재 프로젝트에 필요한 내용만 정리하여 저장.
- 비공개 저장소 2: 원본 파일만 따로 저장.
- 이 대화의 정리본을 프로젝트 저장소에 함께 저장.

이 문서가 대화 정리본이다. 과거 파일을 압축하여 함께 올리는 작업은 중단했다. 기존 작업 폴더와 기존 Git 원격 저장소는 변경하지 않는다. 로그인 정보·개인 인증 파일·설치 환경과 임시 캐시는 저장하지 않는다.

옛 엔젤·페어리·혼합 고용을 요구하는 개조 검사 파일 2개도 현재 구성과 맞지 않아 정리본에서 제외했다. 일반적인 개조 충돌 검사와 원작 버그 검사는 유지했다. 원래 파일은 기존 PC 작업 폴더에 남아 있다.

## 9. 다음 작업자가 지켜야 할 사항

- 수정 전에 `AGENTS.md`, 각 폴더의 README와 이 문서를 읽는다.
- 공용 증가 함수를 다시 바꾸어 메이킹 7/7 또는 2/0 문제가 돌아오지 않게 한다.
- 현재 개조 정본은 `개조/README.md`와 `data/`다. 옛 문서의 엔젤·페어리·혼합 고용 계획을 자동으로 되살리지 않는다.
- 원본은 다른 저장소에서 내려받고 `원본_준비하기.bat`로 준비한다.
- 글꼴·대사 페이지와 음성 연결을 보존한다. 여신 L1:20/L2:98, 상성 설명 L2:100의 기존 동결 결정을 지킨다.
- 새 CHD는 사용자가 요청할 때 만든다. 파일 검사와 실제 게임 화면 확인을 구분하여 설명한다.
- 에뮬레이터에서 확인할 때는 재시작하고 새 게임으로 들어간다. 옛 순간 저장은 이전 대사·코드를 품고 있을 수 있다.
