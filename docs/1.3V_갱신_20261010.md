# 1.3V 문구 수정 배포 — 2026-10-10

랑그릿사 1·2의 게임 중 게임설정에 남아 있던 `전투시ーン`을 **전투표시**로 수정했다. 한글판·개조판 CHD와 원본에 적용하는 xdelta·ZIP 모두 갱신했다. 파일명과 버전 표기는 1.3V를 유지한다.

## 현재 1.3V에 포함된 수정

한글판·개조판 공통:

1. 에그베르트 퇴각 횟수 오류 수정.
2. 이벤트의 용병 고용 수 +2가 해당 인물에게 적용되지 않던 오류 수정.
3. 에스트·오스트의 엘레멘탈 고용 불가 수정.
4. 시나리오 10 발가스 격퇴 후 레온 음성 누락 수정.
5. 메이킹 A수정·D수정 계산 복구. 제보한 워록 선택에서 4/4를 사용자 화면으로 확인했다.
6. 메사이얀소드 등 일반 아이템 설명 118곳의 수치 줄바꿈 정리.
7. 랑그릿사 2의 어색한 말투 70개 대사 수정.
8. 이번 갱신: 게임설정의 전투표시 라벨 수정.

개조판에만 추가하는 항목은 양 게임 공통으로 다음 네 가지다.

- 메사이안 소드의 경험치 2배 효과를 크라운으로 이동.
- 크라운 마법내성 +20.
- 크라운·룬스톤 각각 10P.
- 첫 상점 판매품을 나이프·크라운·룬스톤으로 변경.

전직 후 고용 한도 계산은 이번에 바꾸지 않았다. 헤인의 기본 경로는 워록 3 → 팰러딘 4 → 프리스트 3으로 계산되며, 팰러딘에서 3이었다는 제보는 실제 사용자 세이브 확인 전이다. 이벤트의 고용 수 +2 오류 수정과는 별개다.

## 검사와 한계

- 기본판 전체 빌드의 대사 배치·여신 동결·조사·원작 버그 검사를 완료했다.
- 이전 각 배포본과 전체 디스크 대조: 설정 라벨 두 곳과 해당 섹터의 EDC/ECC만 변경됐다.
- 개조 변경을 별도로 재구성해 전체 트랙과 대조했다. 기본판 대비 두 실행 파일 각각 16바이트만 다르다.
- 두 CHD의 무결성, 재추출한 6개 트랙과 트랙 배치를 확인했다.
- 두 배포 패치를 원본 복사본에 설치해 빌드 결과와 일치함을 확인했다. ZIP 전체 항목도 검사했다.
- 이번 갱신의 실제 에뮬레이터 화면 검사는 하지 않았다.

빌드 당시 작업 폴더에는 별도 Plus 작업이 있었다. 일반 번역 11,774개는 기존 Git 정본과 정확히 같고, 추가된 92개 Plus 번역은 일반 1.3 빌드에서 제외됐다. 이번 Git 갱신에도 Plus 번역·코드·진행 기록은 포함하지 않는다. 일반 빌드에서 호출하지 않는 Plus 전용 도구와 Plus 행을 거르는 작업 중 코드도 로컬에 보존한다.

## 파일과 기록

- 실행 파일: `../1.3V/`의 한글판·개조판 CHD는 로컬에만 보관한다. CHD Git 추적과 LFS 등록을 해제하고, 모든 커밋에서 CHD를 제거한 뒤 같은 이름의 비공개 저장소를 재생성했다. 새 저장소에서 이전 CHD 4개의 LFS 다운로드 요청과 기존 커밋 3개의 조회가 모두 404로 응답함을 확인했다. 소스·문서·차이 패치는 보존했다.
- 배포 패치: `../1.3V 패치/`의 두 ZIP과 각 패키지 폴더.
- 상세 검사값: `../1.3V 패치/제작_검증_기록.md`.
- 최종 배포 파일의 SHA-256 목록: `../분석/1.3문구수정배포_20261010/published_release.json`.
- 문구 변경·개조 구성·CHD·패키지 검사 보고서는 같은 분석 폴더에 있다.
- 조사 기록과 복원한 라벨 그림: `../한글화/docs/1.3_설정문구와_헤인고용수_20261003.md`, `../분석/1.3버그제보_20261003/`.

수정 전 파일과 임시 빌드·설치 검사 복사본은 로컬에 보관하며 Git에서 제외한다. 과거 조사 기록이 참조하는 기계어 검사기 일부는 별도 Plus 조사 도구를 사용하므로 이번 배포 커밋에 포함하지 않는다. 보존된 JSON 결과는 당시 검사 기록이며, 원본 게임 파일이나 사용자 세이브가 아니다. 배포 폴더는 줄바꿈을 자동 변환하지 않아 검사값을 보존한다.
