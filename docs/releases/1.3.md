# 랑그릿사 I & II 1.3V — 한글판·개조판

2026-10-10 갱신. 세가 새턴 일본판 **Dramatic Edition (1M)**용 패치입니다. 한글판과 개조판 모두 랑그릿사 1·2를 포함하며, 게임설정의 일본어 잔여 문구 수정까지 반영했습니다. 버전 표기는 **1.3V**를 유지합니다.

## 다운로드와 판 선택

| 파일 | 내용 |
| --- | --- |
| [Langrisser_1.3_KR_Patch.zip](https://github.com/bbongpark/langrisser-saturn-kr-project/releases/download/v1.3/Langrisser_1.3_KR_Patch.zip) | 한글화와 아래 공통 수정 |
| [Langrisser_1.3_KR_Mod_Patch.zip](https://github.com/bbongpark/langrisser-saturn-kr-project/releases/download/v1.3/Langrisser_1.3_KR_Mod_Patch.zip) | 한글판 전체 내용과 크라운·가격·상점 개조 |

원하는 판의 ZIP 하나만 받으면 됩니다. 두 판 모두 **수정하지 않은 일본판 원본에 직접 적용**하며, 패치를 겹쳐 적용하지 않습니다. 개조판에도 한글화가 포함돼 있습니다. 배포 파일명이 영문인 ZIP은 저장소의 `랑그릿사_1.3V_한글판_패치.zip`·`랑그릿사_1.3V_개조판_패치.zip`과 각각 같은 내용입니다.

ZIP에는 차이 패치, 적용 도구, 설명서가 들어 있습니다. 원본 게임·완성 BIN·CHD는 배포하지 않습니다. GitHub가 별도로 제공하는 `Source code` 압축 파일은 제작 소스입니다.

## 한글판·개조판 공통 변경 내역

현재 1.3V에 포함된 수정입니다. 1~4번은 랑그릿사 2 원작 버그 수정입니다.

1. **에그베르트 퇴각 횟수** 오류 수정.
2. **이벤트 용병 고용 수 +2**가 해당 인물에게 적용되지 않던 오류 수정.
3. **에스트·오스트의 엘레멘탈 고용 불가** 수정.
4. **시나리오 10 발가스 격퇴 후 레온 음성 누락** 수정.
5. **메이킹 A수정·D수정 계산 복구.** 제보된 워록 선택의 4/4 표시를 사용자 화면으로 확인했습니다.
6. **일반 아이템 설명 118곳**의 수치 줄바꿈 정리.
7. **랑그릿사 2 대사 70개**의 어색한 말투 수정.
8. **2026-10-10 추가 반영:** 랑그릿사 1·2 게임 중 게임설정의 `전투시ーン`을 **전투표시**로 수정.

## 개조판 추가 변경 내역

랑그릿사 1·2 모두 다음 내용을 적용합니다. 한글판에는 이 개조가 없습니다.

- 메사이안 소드의 **경험치 2배 효과를 크라운으로 이동**.
- 크라운 **마법내성 +20**.
- 크라운·룬스톤 가격 **각각 10P**.
- 첫 스테이지 상점 판매품을 **나이프·크라운·룬스톤**으로 변경. 스몰실드 제외.

엔젤·페어리 추가 고용, 혼성 용병 고용, 혼성 고용 환급 보조 코드는 포함하지 않습니다. 별도로 작업 중인 **Plus 4.2 이식 시험판도 이 배포본에 포함하지 않습니다.**

## 적용 방법 (Windows)

지원 원본은 **Langrisser - Dramatic Edition (Japan) (1M)**입니다. CUE 1개와 BIN 트랙 6개가 같은 폴더에 있어야 하며, CHD 한 파일에는 직접 적용할 수 없습니다. 적용 도구가 6개 트랙을 모두 검사하므로 다른 판본이면 중단합니다.

1. 원하는 판의 ZIP을 압축 해제합니다.
2. 원본 CUE 파일을 압축을 푼 폴더 안의 `적용하기.bat` 위에 끌어다 놓습니다. 또는 해당 파일을 실행하고 CUE의 전체 경로를 입력합니다.
3. 검사가 끝날 때까지 기다립니다. 약 1GB의 빈 공간이 필요합니다.
4. 원본 폴더에 생성된 결과 폴더에서 CUE를 엽니다.

| 판 | 결과 폴더 | 실행할 CUE |
| --- | --- | --- |
| 한글판 | `Langrisser_KR_v1.3_20261010` | `langrisser-krpoc.cue` |
| 개조판 | `Langrisser_KR_MOD_v1.3_20261010` | `langrisser-mod.cue` |

원본 파일은 보존됩니다. 결과 폴더가 이미 있으면 덮어쓰지 않고 중단합니다. 수정된 문구를 확인할 때는 에뮬레이터를 재부팅하고 게임 내 저장을 불러오세요.

## 검증 범위와 남은 확인

- 두 판의 패치를 원본 복사본에 적용해 완성된 6개 트랙과 CUE가 검증된 빌드와 일치함을 확인했습니다.
- ZIP 전체 항목과 SHA-256 검사, 로컬 CHD 무결성·재추출 검사를 통과했습니다.
- 이번 설정 문구 수정의 실제 에뮬레이터 화면 검사는 하지 않았습니다. 전체 게임의 모든 장면을 확인한 상태도 아닙니다.
- 전직 후 용병 고용 한도 계산은 이번에 변경하지 않았습니다. 헤인 팰러딘의 최대 고용 수가 3부대였다는 제보는 실제 세이브로 확인하지 못했습니다. 이벤트 고용 수 +2 수정과는 별개입니다.
