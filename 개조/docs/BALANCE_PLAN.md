# 밸런스 패치 기획안 (v1 — 리서치 기반 초안)

**작성 2026-08-02.** 웹 리서치(나무위키/dcinside/arca.live/영어권 리뷰·포럼 + SRPG 밸런스
일반론)와 우리가 이미 실증한 두 가지 능력(①데이터 테이블 파이프라인 완성 — 정본
`BALANCE_PIPELINE.md`, ②SH-2 실행 코드 패치 가능 — 정본 `HANDOFF_BALANCE.md` 세션1)을
근거로 세운 초안이다. **아직 수치는 확정이 아니다** — 사용자와 논의해서 방향을 정한 뒤
착수한다.

---

## 1. 기본 원칙

리서치에서 확인된 두 건의 실제 팬 패치(dcinside 메사이야 갤러리판, 게임잡지 갤러리판)가
공통으로 따른 패턴 + SRPG 밸런스 일반론을 종합하면:

1. **파워 커브 유지가 목표다, 숫자 맞추기가 목표가 아니다.** "적 성장 곡선이 플레이어
   성장과 비례해야 한다"(Game Wisdom) — 후반 마법 남발로 전투가 무너지는 문제가
   반복 지적되므로, 초반보다 **후반 저항력/보스 스탯 상향**이 핵심 레버가 될 가능성이 높다.
2. **숫자보다 메커니즘을 먼저 본다.** 콜린 조한슨의 원칙대로, 스탯을 깎기 전에 "왜
   이 조합이 게임을 뚫어버리는가"(예: 마법사+고방어 호위 조합, 어게인 무한콤보)부터
   구조적으로 분석한다.
3. **격차 해소이지 하향평준화가 아니다.** 실제 팬 패치들은 최약체를 최강체 수준으로
   올리기보다, **가장 뒤처진 병종(서펜마스터 등)을 상위권과 격차 줄이는 쪽**으로 손댔다.
4. **사기 콤보/버그는 패치, 스타일 차이는 존중.** 무료 최상급 장비, 데이터 결함(전직
   역전 등)은 명백한 버그라 고친다. 반면 "드래곤라이더가 강하다"류는 원 게임 디자인의
   일부일 수 있어 신중히 접근(비행 유닛이 원래 강한 건 장르 보편적 설계).
5. **작은 변경 → 실기 검증 → 반복.** `HANDOFF_BALANCE.md`가 이미 권고한 방식 그대로,
   전 병종을 한 번에 갈아엎지 않고 카테고리별로 나눠 검증하며 진행한다.

## 2. 리서치로 확인된 이슈 — 신뢰도별 정리

전체 리서치 원본은 이 세션 대화 기록 참고(에이전트 리서치, 2026-08-02). 신뢰도
표기: **확실**(1차 출처 원문 확인) / **간접**(검색 스니펫 경유, 원문 미확인) /
**추측**(2차 정보 종합).

### 확실 — 우선 검증·반영 후보

| 이슈 | 내용 | 대응 후보 |
|---|---|---|
| 서펜로드(4차) > 서펜마스터(5차) 용병 수정치 역전 | 상위 전직이 하위보다 약한 명백한 데이터 결함 | `class_dat.py`로 실측 확인 후 서펜마스터 상향 |
| 에그버트/자벨러 마법 세트 비대칭 | 적 소유 시엔 메테오 사용, 플레이어가 키우면 못 씀 | `character_dat.py`/`promotion_dat.py`로 마법 플래그 대조 — 데이터 원인 규명 먼저 |
| 마법사 계열 극단적 양면성 | 고방어 호위+광역마법으로 게임 다수 챕터 돌파 가능 / 방어력 낮아 궁병 1방에 사망 | 마법사 AT/마법위력 소폭 하향보단 **후반 적 마법저항 상향**이 우선순위(원칙1) |
| 드래곤라이더 최강 클래스(비행+고공격) | 후반 드래곤라이더 2기+마법사 1기로 클리어 가능 | 지형 지형 이동 패널티 자체보단 **HP/AT 소폭 조정** 검토, 과도한 너프는 비추천(원칙3 반례 — 이건 원래 강해야 하는 클래스) |
| 다크가드/로열호스/아크데몬 용병이 적 전용 | 아군이 후반 용병 전력에서 상대적으로 밀림 | `stage_dat.py`/`shop_dat.py`로 후반 상점·전직에 아군 획득 경로 추가 검토 |
| 초기숨김상점 무료 최상급 장비 | 실질 사기 콤보, 팬패치 두 건 모두 이걸 막음 | `shop_dat.py` 판매가/조건 조정 |
| 챌린지(회차) 모드 적 스탯만 20%씩 누적 상승 | 아군 보정 없이 난이도만 오름 | 스테이지 보상(`stage_reward_dat.py`)에 회차 보정 추가 검토(구현 난도 높을 수 있음 — 후순위) |

### 간접 — 실기 검증 먼저 필요

| 이슈 | 검증 방법 |
|---|---|
| 세이지 2인 + 발리스타 + 어게인 마법 무한 행동 콤보 | emucap으로 재현 시도 — 실존하면 `magic_dat.py`의 어게인 사거리/MP 소모 조정으로 대응 |
| 새턴/PS 이식판 궁병 원거리 공격으로 인한 적장 저격 전략 강제화 | 이건 **전투 시스템 자체**(공격방식 도입 여부) 문제라 `fight_dat.py`로 조정 가능한지 확인 필요. 데이터 문제가 아니라 스테이지 설계(적 지휘관 배치) 문제일 수도 있음 |
| 프레이어(지휘관 저격 클래스)로 고난도 스테이지 우회 | 개별 스테이지 AI/배치(`stage_dat.py`) 케이스 바이 케이스 |
| 특정 시나리오 AI가 최적 플레이를 못 함(제시카 메테오 미사용 등) | AI 로직은 코드 영역 — 데이터 테이블로 해결 안 될 가능성 높음, 손대지 않는 쪽 권장(리스크 대비 효과 낮음) |

### 참고만 (원 디자인일 가능성, 손대지 않을 후보)

- 무기/병종 상성 삼각형류 설계 자체에 대한 커뮤니티 찬반(Fire Emblem 사례) — 랑그릿사는
  이미 `matchup_dat.py`(18×18 상성표)가 있으니 이건 "새로 만들 것"이 아니라 "기존 표가
  합리적인지 감사"하는 정도로 충분.

## 4. 제안하는 착수 순서 (단계별)

**0단계 — 감사(현재 데이터 실측)**
`extract_balance.py`로 전체 테이블을 JSON으로 뽑아, 리서치에서 지목된 구체 항목부터
실측 확인: 서펜로드 vs 서펜마스터 수정치, 에그버트 마법 플래그, 드래곤라이더 스탯,
초기숨김상점 목록. **여기서 실제로 결함이 확인된 것만 다음 단계로 넘긴다** — 간접
정보이므로 데이터가 다르면 그쪽을 따른다.

**1단계 — 명백한 버그 수정 (저위험)**
- 서펜마스터 용병 수정치 상향(서펜로드보다는 위로)
- 에그버트/자벨러 마법 세트 정합화
- 초기숨김상점 무료 최상급 장비 차단

**2단계 — 후반 난이도 곡선 (중위험, `class_dat.py` 마법저항 필드 위주)**
- 보스/네임드 적 마법저항 상향 (실제 팬패치가 쓴 레버)
- 필요시 후반 스테이지 네임드 스탯 상향

**3단계 — 경제/장비 밸런스 (중위험, `shop_dat.py`+`item_dat.py`)**
- 다크가드/로열호스/아크데몬류 아군 획득 경로 검토
- 아이템 가격 재조정

**4단계 — 콤보/코드 레벨 이슈 (고위험, SH-2 패치 가능성 있음)**
- 어게인 무한콤보 실기 재현 → 확인되면 마법 데이터로 대응(코드 패치까지는 불필요할 가능성)
- 궁병 사거리 이슈는 데이터 테이블 밖일 가능성 높아 **가장 마지막, 필요성 재평가 후 착수**

매 단계마다 `verify_disc_layout.py`·`verify_goddess_frozen.py`로 한글화 자산 무결성 확인
후, emucap으로 실기 검증(새 게임 진입 — 세이브스테이트 금지)까지 하고 다음 단계로.

## 5. 리스크·주의사항 (기존 `CLAUDE.md`/`HANDOFF_BALANCE.md` 규칙 재확인)

- 여신 블록(`L1:20`·`L2:98`)·유닛 상성표(`L2:100`) 동결 — 밸런스 변경 대상에서 제외.
- `LANG*.BIN`에 심어진 한글화 자산(반각공백 패치·카타카나 리다이렉트·병종명 케이브)을
  덮지 않도록 매 코드 패치 전 대상 구간이 원본과 바이트 동일한지 먼저 diff(이번 세션
  코드 패치 때 실제로 이렇게 검증함 — 좋은 선례로 계속 사용).
  이번 세션에 새로 만든 `Next/original/` 추출본이 diff 비교의 기준점이 된다.
- L1(랑그릿사1) 오프셋은 상당수 미검증 — 확실한 것부터면 L2(랑그릿사2) 우선.
- 리서치 출처 중 나무위키발 정보는 전부 간접 인용(원문 미확인)이라 **실측/실기로
  재확인 후에만 반영**한다.
- 코드 패치는 데이터 패치보다 리버싱 비용이 훨씬 크다(이번 세션 1건에 브레이크포인트
  시행착오 다수) — 데이터 테이블로 해결되는 문제는 항상 그쪽을 먼저 시도.
