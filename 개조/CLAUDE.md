# 개조 전용 작업 규칙

번역 정본을 복제하지 않는다. project.json의 한글화 프로젝트는 읽기 전용 입력이다. data/balance와 data/code_patches.json을 수정하고 scripts/rebuild.py로 빌드한다. 최신 한글화 결과를 받아 기존 개조를 재적용한다. 서펜마스터·전체내성+10 등 옛 완료 기록은 현재 v1.2에 없으므로 자동 복구하지 않는다. 개조/README.md가 현재 상태 기준이다. 큰 기획서는 미확정 제안이다.

## 사용자와 대화
- 한국어로, 비전문가도 이해할 수 있는 쉬운 말과 짧은 문장으로 설명한다.
- 수정한 대사는 해당 대사 전체를 보여준다.

## 보존할 결정
- 새 CHD 생성은 사용자 요청 시에만 한다.
- 게임 화면 이동은 사용자가 맡는다. 임의로 메뉴를 탐색하지 않는다.
- 여신 L1:20/L2:98과 L2:100 상성 설명은 기존 결정대로 동결·보류한다. 조판 변경도 포함한다.
- 대사 페이지는 음성과 연결된다. 원문 경계와 페이지 수를 함부로 줄이지 않는다.
- 대사는 14칸, 첫 페이지 3줄·이후 4줄. 나레이션 16×7, 조건·엔딩 16×4. 여신 등은 예외다.
- 나레이션 {05}는 한 칸 들여쓰기다. 이름 코드 09 XX와 MTE 04 XX의 인자를 제어코드로 오독하지 않는다.
- 16픽셀 네오둥근모, 8픽셀 달무리(64로 렌더 후 블록 평균) 정책을 유지한다.
- 새 빌드 확인은 순간 저장이 아닌 재부팅·게임 내 진입으로 한다. 에뮬레이터 파일 잠금에 주의한다.
- 빈 타일처럼 보여도 게임이 사용한다. pnt_refs 가드와 한글화 코드가 쓰는 영역을 보존한다.
- stdout 재설정은 reconfigure를 사용한다. TextIOWrapper로 재포장하지 않는다.
