# 개조 전용 프로젝트

완성된 한글화에 게임 수치·아이템·경험치 규칙을 추가합니다. 번역문을 이곳에 복제하지 않습니다.

2026-10-10 1.3V 배포 갱신: L1·L2 게임설정의 `전투시ーン` → **전투표시** 수정을 일반 개조판 BIN/CUE·CHD·xdelta·ZIP에 반영했습니다. 현재 개조는 양 게임 공통으로 **메사이안 소드의 경험치 2배 효과를 크라운으로 이동, 크라운 마법내성 +20, 크라운·룬스톤 각각 10P, 첫 상점 나이프·크라운·룬스톤**입니다. 용병 고용 규칙과 별도 Plus 시험판은 변경하지 않았습니다. 일반 1.3V CHD에는 Plus 이식 내용이 포함되지 않습니다. 파일 검사는 통과했으며 실제 게임 화면은 미확인입니다. 검사 기록: `../분석/1.3문구수정배포_20261010/`.

## 사용 순서

1. 한글화도 수정했다면 먼저 옆 `한글화/한글화_빌드.bat`를 실행합니다.
2. 이 폴더의 `개조_빌드.bat`를 실행합니다.
3. `build/disc-mod/langrisser-mod.cue`를 에뮬레이터에서 엽니다.

**한글화만 바꾼 경우에도 이 빌드를 다시 실행하면 새 한글화에 기존 개조가 다시 들어갑니다.** 한글화 폴더의 파일은 수정하지 않습니다. 이전 개조 결과는 `disc-mod.previous` 또는 날짜를 붙인 폴더로 남깁니다.

## 현재 개조 (1.3V, 2026-09-30 변경)

- L1·L2 경험치 2배 효과를 메사이안 소드에서 크라운으로 이동
- L1·L2 크라운 마법내성 +20 유지
- L1·L2 크라운·룬스톤 가격 10P
- L1·L2 첫 스테이지 상점: `나이프·크라운·룬스톤` 3개

첫 상점의 스몰실드를 빼고 마지막 칸은 목록 종료값 0으로 둡니다. 네 칸을 모두 채워 다음 상점 목록이 이어 표시되는 문제를 막습니다.

경험치 판정 세 곳씩에서 무기 칸의 메사이안 소드 대신 장비 칸의 크라운을 확인합니다. 메사이안 소드의 다른 능력치는 그대로입니다.

5차 직업 엔젤 추가, 1차 직업·초기 목록 페어리 추가, 혼성 용병 고용과 환급 보조 코드는 제거했습니다. 직업표와 해당 고용 코드는 한글화 기본판 상태를 사용합니다.

한글화 기본판의 원작 버그 4종 수정과 메이킹 A/D 수정은 그대로 상속합니다. 이전 개조 입력은 `../분석/개조설정변경_20260930/기존입력/`에 보관했습니다.

## 개조를 수정할 파일

- `data/balance/*.json`: 병종·아이템·상점·마법·유닛 배치 등의 수정표 13개
- `data/code_patches.json`: 경험치 코드와 L1 아이템/상점의 직접 수정 명세
- `project.json`: 한글화 프로젝트 위치. 기본값 `../한글화`
- `scripts/balance/`: 데이터 해석 도구

**수정표와 코드 패치 명세는 Git에 저장할 입력 파일입니다.** `build/` 아래의 결과물과 분리했습니다.

## 한글화 업데이트를 받는 방식

`scripts/rebuild.py`는 검증된 한글화 결과를 메모리로 읽고 **원본과 달라지도록 지정한 바이트만** 수정합니다. 수정표에 들어 있는 변경 없는 값은 새 한글화 위에 덮어쓰지 않습니다. 새 한글화가 개조와 같은 자리를 바꾸었다면 충돌을 알려주고 멈춥니다.

텍스트·폰트 처리 코드는 `project.json`이 가리키는 한글화 프로젝트에서 읽습니다. 개조 쪽에 따로 복제해 두 버전이 벌어지지 않게 했습니다. 디스크 결과물은 독립 복사본으로 만들어 한글화와 연결되지 않습니다.

새 CHD는 자동 생성하지 않습니다. 기존 v1.2 CHD는 이전 `Next/build` 보관본에 있습니다.

## 고급 도구

일반 작업은 `개조_빌드.bat`를 사용합니다. `scripts/balance/apply_balance.py`와 `apply_stage.py`는 옛 저수준 도구이며 최종 코드 패치를 합치지 않습니다. 전체 최신 빌드의 대체물로 쓰지 않습니다.

`extract_balance.py`와 `extract_stage.py`의 기본 출력은 `build/extracted-balance/`입니다. 추출만으로 정본 수정표 `data/balance/`를 덮지 않도록 바꿨습니다. 추출 내용 전체를 정본에 복사하면 개조 의도가 달라질 수 있으니 비교 후 필요한 값만 반영합니다.

전직 표의 의미, 일부 L1 주소, 스테이지 일부 행동값은 미확정입니다. 유닛 수나 파일 크기를 늘리는 편집은 지원하지 않습니다. 예전 문서의 ‘모든 탭 완료’를 모든 게임 규칙의 해석 완료로 받아들이지 않습니다.
