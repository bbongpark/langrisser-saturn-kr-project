# 한글화 전용 프로젝트

대사·이름·메뉴·폰트·줄 배치는 이 폴더에서만 수정합니다. 크라운 효과나 가격 같은 게임 개조는 포함하지 않습니다.

2026-10-10: L1·L2 게임설정의 `전투시ーン`을 **전투표시**로 수정한 전체 빌드를 현재 BIN/CUE와 `../1.3V/`의 두 CHD, 배포 xdelta·ZIP에 반영했습니다. 파일·패치 검사는 통과했고 실제 게임 화면 확인은 하지 않았습니다. 기록: `docs/1.3_설정문구와_헤인고용수_20261003.md`.

## 사용 순서

1. `대사검수툴.bat`를 열어 번역문을 수정합니다. 표시되는 주소를 브라우저에서 엽니다.
2. `한글화_빌드.bat`를 실행합니다.
3. 완료되면 `build/disc-krpoc/langrisser-krpoc.cue`를 에뮬레이터에서 엽니다.

처음 사용할 때만 `환경_준비.bat`를 실행합니다. Python 3가 필요하며 전용 실행 환경에 Pillow 11.3.0과 NumPy 2.2.6을 설치합니다. 현재 PC에는 준비했습니다.

**한글화만 업데이트할 때는 여기서 끝입니다.** 개조판에도 적용하려면 옆 `개조` 폴더의 `개조_빌드.bat`를 실행합니다. 기존 개조판은 자동으로 바뀌지 않습니다.

## 관리할 파일

- `build/worksheet_dedup_final.json`: 번역 정본. 옛 경로와 기존 검수 도구 호환을 위해 위치 유지. 이 파일은 Git 제외 대상이 아닙니다.
- `build/classnames.json`, `steam_charnames.json`, `steam_glossary.json`: 이름·용어
- `scripts/`: 한글화·검수 도구
- `fonts/`: 네오둥근모와 달무리
- `original/`: 원본에서 추출한 11개 파일
- `docs/HANDOFF.md`: 과거 한글화 이력
- `docs/검수_사용자판단.md`: 용어·문체의 사용자 결정

## 빌드 구조

원본 + 번역문 → 텍스트·폰트 삽입 → 디스크 조립 → 그림 메뉴·작은 글자 삽입 → 검사 → `translation-manifest.json` 기록.

빌드 기록에는 입력 파일과 출력 트랙의 내용 식별값이 들어갑니다. 개조 프로젝트는 이 기록으로 새 한글화가 완성됐는지 확인합니다. 번역문만 저장하고 아직 빌드하지 않은 경우 개조 빌드를 중단합니다.

각 트랙은 독립 복사본입니다. 한글화 결과를 수정해도 제공된 원본이나 개조 결과로 전파되지 않습니다.

원본 디스크는 기본적으로 상위 폴더의 `Langrisser - Dramatic Edition (Japan) (1M)`에서 읽습니다. 다른 위치라면 `LANGRISSER_DISC` 환경변수를 지정합니다. CHD는 자동 생성하지 않습니다.

## 주의

- `reinsert_text.py`만 실행하지 말고 전체 빌드를 사용합니다.
- 여신 L1:20/L2:98, 상성 설명 L2:100은 기존 사용자 결정대로 보류합니다.
- 대사 페이지는 음성과 연결되므로 원문 경계를 함부로 줄이지 않습니다.
- 순간 저장을 불러오면 옛 글자 데이터가 남을 수 있습니다. 새로 부팅해 확인합니다.
- 전체 루트 플레이 검증은 별도입니다. 자동 검사는 화면·음성 전체를 보증하지 않습니다.

기존 `Next/`, `kr-patch/`는 이전 작업 보관본입니다. 새 수정은 이 폴더에 합니다.
