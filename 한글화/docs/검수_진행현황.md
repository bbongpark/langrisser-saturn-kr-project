 · # 전수 검수 진행 현황

세션24부터 **L1·L2 전 시나리오를 원문과 한 줄씩 대조해 정독**하며 검수한다.
한 장을 끝낼 때마다 이 파일의 체크박스를 갱신한다. 세션이 끊겨도 여기부터 이어받으면 된다.

## 한 장을 처리하는 절차 (매번 이대로)
```
1) 진단      python scripts/audit_pages.py L2 <n>      # 원문 대비 페이지 초과(대사만)
             python scripts/audit_register.py L2 <n>   # 존대/평어 층위
             python scripts/audit_wrap.py L2 <n>       # 어절 잘림
2) 정독      python scripts/dump_scenario_kr.py L2 <n> --jp
             → **원문과 번역을 한 줄씩 대조해 읽는다.** 도구는 오역·용어·어색함을 못 잡는다.
3) 수정안    조판기(rewrap_markup)를 reinsert와 같은 인자로 돌려 전/후를 확인.
             ⚠ `[NL]`을 손으로 박지 말고 **문장을 다듬어** 워드랩 위치를 옮긴다(세션21 규칙 ②).
             ⚠ 페이지는 **원문과 같은 수까지만** 줄인다(음성 구간 경계).
             ⚠ 고치기 전 `len(ids)==1` 확인. 아니면 다른 시나리오와 공유하는 문자열이다.
4) 반영      워크시트 저장 → python scripts/rebuild.py
5) 검증      verify_disc_layout.py · verify_disc_layout.py --conditions · verify_goddess_frozen.py
             audit_pages / audit_wrap 재실행으로 0건 확인
6) 기록      이 파일 체크 + 판단 필요한 건 docs/검수_사용자판단.md 에 추가
```
⛔ **CHD는 사용자가 요청할 때만 굽는다.** 기본 종료 지점은 `build/disc-krpoc`.

## 검수 관점 (5종)
| 관점 | 도구 | 도구가 못 잡는 것 |
|---|---|---|
| 페이지 초과 | `audit_pages.py` | — (객관적) |
| 어절 잘림 | `audit_wrap.py` | 원문이 강제한 줄바꿈인지 |
| 존대/평어 | `audit_register.py` | 여성 보통체(`〜わ`)는 한국어로 존댓말이 맞다(리아나) |
| 표준어/맞춤법 | `audit_style.py` | 의도된 말투(`-슴다`) |
| **오역·용어·자연스러움** | **없음 — 정독만이 방법** | 전부 |
