# 랑그릿사 I & II 새턴 한글화·개조 프로젝트

현재 작업에 필요한 번역문, 글꼴, 제작 도구, 검사, 설명서와 최신 1.3V 차이 패치를 정리한 비공개 저장소입니다.

## 저장 범위

- Git에는 한글화·개조 소스와 문서, 원본에 적용하는 xdelta 패치와 패치 ZIP을 보관합니다.
- 원본 게임과 완성된 CHD·BIN·ISO는 로컬에서만 사용하며 업로드하지 않습니다.

2026-10-10에 CHD 추적을 해제하고 LFS 규칙과 Git 제외 예외를 제거했습니다. 로컬 CHD와 기존 작업 파일은 유지합니다. 과거 업로드 이력과 서버 LFS 원본의 완전 제거는 별도 정리 단계입니다.

## 현재 완성본

2026-10-10: 한글판·개조판의 L1·L2 게임설정 문구 `전투시ーン`을 **전투표시**로 수정했습니다. 아래 CHD와 배포 패치·ZIP에 모두 반영했습니다. 기존 개조 구성은 유지했습니다. CHD 무결성·6개 트랙 재추출·패치 설치·ZIP 검사를 통과했으며 실제 게임 화면 검사는 하지 않았습니다.

- `1.3V/`: 로컬 CHD 보관 위치입니다. Git에는 검증 안내만 포함하며 CHD는 포함하지 않습니다.
- `1.3V 패치/`: 원본에 적용하는 배포용 패치와 적용 설명서.
- `docs/1.3V_갱신_20261010.md`: 이번 수정, 현재 1.3V 수정 목록과 검사 범위.
- `docs/세션_정리_20260930.md`: 이 대화의 결정, 버그 원인과 해결, 검사 결과, 남은 확인 사항.
- `한글화/README.md`, `개조/README.md`: 각 작업의 자세한 방법.

## 새 PC에서 이어서 작업하기

1. Git과 Python 3를 설치합니다.
2. 아래 명령으로 작업 저장소를 내려받습니다. GitHub 로그인 권한이 필요합니다.

```powershell
git clone https://github.com/bbongpark/langrisser-saturn-kr-project.git
cd langrisser-saturn-kr-project
```

3. 본인이 보유한 지원 원본의 BIN/CUE와 필요한 추출 자료를 로컬에 준비합니다. 기존 로컬 원본 보관 폴더가 있다면 `원본_준비하기.bat`로 검사·복사할 수 있습니다. 원본 파일은 Git에서 제외됩니다.
4. `한글화/환경_준비.bat`를 실행합니다.
5. 번역을 고칠 때는 `한글화/대사검수툴.bat` → `한글화/한글화_빌드.bat` 순서로 실행합니다.
6. 개조판을 만들 때는 한글화 빌드가 끝난 뒤 `개조/개조_빌드.bat`를 실행합니다.

게임에 적용할 때는 `1.3V 패치/`의 원하는 판 ZIP을 사용합니다. 패치만으로는 실행되지 않으며 지원하는 원본이 필요합니다.

## 현재 개조판

랑그릿사 1·2 모두 다음 네 항목만 추가합니다.

- 메사이안 소드의 경험치 2배 효과를 크라운으로 이동.
- 크라운 마법 내성 +20.
- 크라운·룬스톤 가격 10P.
- 첫 스테이지 상점은 나이프·크라운·룬스톤 3개. 스몰실드 제외.

엔젤·페어리 추가, 용병 혼합 고용, 혼합 고용 환급 보조 코드는 현재 개조판에 없습니다.

한글판에는 크라운·상점 개조가 없습니다. 두 판 모두 원작 버그 4종 수정과 메이킹 계산 복구를 공유합니다.

## 저장할 입력 파일

번역 정본은 `한글화/build/worksheet_dedup_final.json`입니다. `build`라는 폴더 이름이어도 이 파일과 이름·용어 JSON 3개는 반드시 저장합니다. 다른 빌드 결과는 다시 만들 수 있습니다.

개조 정본은 `개조/data/`입니다. 한글화의 번역문을 개조 폴더에 복제하지 않습니다.

게임 전체를 끝까지 플레이하여 모든 장면을 확인한 상태는 아닙니다. 확인 범위는 세션 정리 문서를 참고하세요.
